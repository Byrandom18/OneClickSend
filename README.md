# 1 клик

Приложение для Android: фото собеседнику в одно нажатие.

Вы один раз выбираете чат в Telegram или диалог сообщества ВКонтакте. Дальше на экране одна большая кнопка. Нажали — основная камера снимает кадр и сразу отправляет его в этот чат отдельным сообщением. Чат заново выбирать не нужно.

## Зачем это

Обычная камера или мессенджер требуют несколько шагов: снимок, шаринг, выбор чата, подтверждение. Здесь цепочка короткая: открыл приложение → нажал кнопку → фото уже у собеседника.

Типичные случаи: быстро скинуть то, что видишь; держать телефон как «кнопку отправки» в один заранее выбранный чат.

## Что делает приложение

1. При первом запуске предлагает выбрать канал: **Telegram** или **группа ВКонтакте**.
2. Просит вставить токен бота или ключ сообщества. Ключ сохраняется на телефоне, пересборка не нужна.
3. Показывает список чатов (или принимает id вручную). Выбор сохраняется.
4. Открывает превью основной камеры и большую кнопку спуска.
5. По нажатию:
   - делает обычное фото (без вспышки, без подписи, без вибрации);
   - поворачивает кадр по положению телефона (портрет или альбом);
   - сразу отправляет снимок в сохранённый чат;
   - не кладёт фото в галерею — файл живёт во временной папке и удаляется после отправки.
6. Каждое нажатие — новое сообщение. Можно жать подряд: снимки встают в очередь.
7. Чат и ключи можно сменить кнопкой над затвором.

На экране камеры видно, куда уходит фото и статус: отправка, очередь, успех или ошибка.

## Чего приложение не делает

- Не пишет от вашего личного аккаунта Telegram: сообщения идут **от бота**.
- Не пишет от вашего личного аккаунта VK: сообщения идут **от имени сообщества**.
- Нет фронтальной камеры, вспышки, видео, подписей и сохранения в галерею.
- Интерфейс камеры остаётся вертикальным; ориентация меняется у самого снимка.

## Что нужно

- Компьютер с [Android Studio](https://developer.android.com/studio)
- Телефон или эмулятор: **Android 8.0** или новее, камера и интернет
- Для Telegram: бот от [@BotFather](https://t.me/BotFather)
- Для VK: сообщество с включёнными сообщениями и ключ API сообщества

## Сборка и запуск

1. Установите Android Studio и Android SDK (API 35).
2. Откройте папку проекта: **File → Open**.
3. Дождитесь Gradle Sync.
4. Подключите телефон с отладкой по USB или запустите эмулятор.
5. **Run**.

Готовый APK: **Build → Build APK(s)** или `gradlew.bat assembleDebug`.  
Файл: `app\build\outputs\apk\debug\app-debug.apk`.

Ключи вставляются уже в установленном приложении. Пересобирать проект после смены токена не нужно.

## Ключи бота и сообщества

Ключи вставляются **в самом приложении** и хранятся только на телефоне:

1. Выберите Telegram или группу VK.
2. Вставьте токен бота или ключ сообщества.
3. Нажмите «Проверить ключ», затем выберите чат.

Чтобы сменить ключ позже: на экране камеры **Сменить чат или ключ** → нужный канал → вставьте новый ключ. Либо на экране списка чатов нажмите **Сменить ключ**.

Токены не уходят в репозиторий. Резервные копии Android для этого приложения выключены (`allowBackup=false`).

Для разработки можно по-прежнему положить значения в `secrets.properties` (файл в `.gitignore`). Они подставятся как запасной вариант, пока в приложении не сохранён свой ключ. В репозитории остаётся только пустой `secrets.properties.example`. Не делайте `git add -f secrets.properties`.

## Telegram

Сообщения приходят собеседнику **от бота**, не от вашего аккаунта.

1. В Telegram откройте [@BotFather](https://t.me/BotFather), команда `/newbot`.
2. В приложении выберите Telegram и вставьте токен.
3. Собеседник должен написать боту `/start`. Либо добавьте бота в общий чат и напишите там сообщение.
4. Нажмите «Проверить ключ» и укажите чат.

Если списка нет, введите `chat_id` (число) или `@username` публичного чата.

## Группа ВКонтакте

Нужен **ключ сообщества**, не личный ключ пользователя. Фото уходят **от имени группы**.

1. Создайте или откройте сообщество: [vk.com/groups](https://vk.com/groups).
2. Включите сообщения: **Управление → Сообщения → Сообщения сообщества**.
3. Создайте ключ:
   - **Управление → Настройки → Работа с API → Создать ключ**;
   - или `https://vk.com/clubID?act=tokens` (вместо `ID` — номер сообщества).
4. Права ключа: **photos** и **messages**.
5. В приложении выберите группу VK и вставьте ключ.
6. Человек, которому отправляете фото, должен **написать сообществу в личку** (или разрешить сообщения). После этого он появится в списке.
7. Для беседы добавьте сообщество в чат. `peer_id` беседы: `2000000000 + номер_чата`.

Документация VK: [ключ доступа сообщества](https://dev.vk.com/ru/api/access-token/getting-started).

Если API отвечает отказом доступа — проверьте, что ключ именно сообщества, а не пользователя, и что сообщения в группе включены.

## Как пользоваться

1. Выберите Telegram или группу VK, вставьте ключ, затем чат. Это запоминается.
2. Разрешите доступ к камере.
3. Нажимайте большую кнопку — каждое нажатие отдельное фото в тот же чат.
4. Поверните телефон, если нужен горизонтальный кадр.
5. Чтобы сменить чат, мессенджер или ключ, нажмите «Сменить чат или ключ».

Нужен интернет в момент отправки. Если сеть пропала, на экране будет ошибка; снимок в галерею не сохранится — можно просто снять ещё раз.
