# 1 клик

Приложение для Android: фото собеседнику в одно нажатие.

Вы один раз выбираете чат в Telegram или диалог сообщества ВКонтакте и вставляете ключ. Дальше на экране одна большая кнопка. Нажали — основная камера снимает кадр и сразу отправляет его в этот чат отдельным сообщением. Чат заново выбирать не нужно.

Сообщения в Telegram идут **от бота**, во ВКонтакте — **от имени сообщества**, не от вашего личного аккаунта.

## Установка

Нужен телефон на **Android 8.0** или новее, с камерой и интернетом.

1. Откройте вкладку **Releases** в этом репозитории.
2. Скачайте файл **`.apk`** из последнего релиза.
3. Откройте скачанный файл на телефоне и установите.
4. Если система предупредит о неизвестном источнике — разрешите установку из приложения, через которое открыли файл (Файлы, Chrome, Telegram и т.п.).

Ключи в APK не вшиты: их вставляете уже в установленном приложении.

## Telegram

### 1. Создайте бота

1. В Telegram откройте [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot` и следуйте подсказкам: имя бота и уникальный username (должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** — длинную строку вида `123456:ABC-DEF...`. Скопируйте её и никому не пересылайте.

### 2. Начните диалог

Бот не может сам написать человеку первым.

- Для лички: собеседник открывает вашего бота и отправляет `/start`.
- Для группы: добавьте бота в чат и напишите там любое сообщение.

После этого чат появится в списке в приложении. Если списка нет — введите `chat_id` (число) или `@username` публичного чата.

### 3. Вставьте токен в приложение

1. Откройте **1 клик**.
2. Выберите **Telegram**.
3. Вставьте токен бота и нажмите **Проверить ключ**.
4. Выберите чат и нажмите **Сохранить и открыть камеру**.
5. Разрешите доступ к камере.

Токен сохраняется на телефоне.

## Группа ВКонтакте

Нужен **ключ сообщества**, не личный ключ пользователя.

### 1. Создайте сообщество и включите сообщения

1. Создайте или откройте сообщество: [vk.com/groups](https://vk.com/groups).
2. **Управление → Сообщения** — включите **Сообщения сообщества**.

### 2. Получите ключ

1. **Управление → Настройки → Работа с API → Создать ключ**.  
   Либо откройте `https://vk.com/clubID?act=tokens` (вместо `ID` — номер сообщества).
2. Отметьте права **photos** и **messages**.
3. Скопируйте ключ.

Подробнее: [ключ доступа сообщества](https://dev.vk.com/ru/api/access-token/getting-started).

### 3. Начните диалог

Сообщество не может само написать человеку первым. Собеседник должен **написать сообществу в личку** (или разрешить сообщения). После этого диалог появится в списке.

Для беседы добавьте сообщество в чат. `peer_id` беседы: `2000000000 + номер_чата`.

### 4. Вставьте ключ в приложение

1. Откройте **1 клик**.
2. Выберите **Группа ВКонтакте**.
3. Вставьте ключ сообщества и нажмите **Проверить ключ**.
4. Выберите чат и нажмите **Сохранить и открыть камеру**.
5. Разрешите доступ к камере.

Ключ сохраняется на телефоне.

## Как пользоваться

1. Нажимайте большую кнопку — каждое нажатие отдельное фото в выбранный чат.
2. Поверните телефон, если нужен горизонтальный кадр.
3. Чтобы сменить чат, мессенджер или ключ: **Сменить чат или ключ**. На экране списка чатов можно нажать **Сменить ключ**.

Нужен интернет в момент отправки. Фото в галерею не сохраняются. Вспышки, подписи и вибрации нет.

## Если что-то не так

- Телефон не ставит APK — разрешите установку из неизвестного источника для приложения, из которого открыли файл.
- Список чатов пуст — сначала напишите боту `/start` или сообществу VK в личку, затем **Обновить список**.
- VK отвечает отказом доступа — ключ должен быть **сообщества**, не пользователя; сообщения в группе должны быть включены.
- На телефоне уже стояла старая тестовая сборка — удалите её и поставьте APK из релизов заново.
